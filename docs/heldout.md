# Held-out worlds

The held-out worlds use different seeds (`config/heldout.yaml`): different catalogues, query sets, purchase
histories and burst schedules, generated by the same world rules. They were evaluated once, after the gate was set
on the development worlds. `config/heldout.lock` records when, with which settings (a hash of the config files)
and on which seeds. `python -m tfs.eval.cli heldout` refuses to run while that file exists.
